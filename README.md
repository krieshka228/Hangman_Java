# Игра «Виселица» (Hangman)

Консольная игра «Виселица», написанная на языке Java. Проект реализует классическую механику угадывания слов по буквам.

## Описание
Программа запускается через главное меню, из которого пользователь может начать игру. Слова для угадывания загружаются из текстового файла `Words.txt`. Игра ведет подсчет ошибок и определяет победу или поражение.

## Технологии
* Язык: Java (Core)
* Среда разработки: IntelliJ IDEA (или любая другая IDE)
* Система контроля версий: Git

## Структура проекта
* `src/Program.java` — точка входа в программу (содержит метод `main`). Создает объект игры и запускает главное меню.
* `src/Game.java` — основной класс с игровой логикой (обработка меню, цикл игры, проверка букв, условия победы/поражения).
* `Words.txt` — текстовый файл, содержащий банк слов для игры.
* `.gitignore` — файл для исключения временных файлов из репозитория.

## Как запустить
1. Убедитесь, что у вас установлен JDK (Java Development Kit) версии 8 или выше.
2. Склонируйте репозиторий на свой компьютер.
3. Откройте проект в вашей IDE (например, IntelliJ IDEA).
4. Найдите файл `src/Program.java`.
5. Нажмите правой кнопкой мыши на метод `main` и выберите Run 'Program.main()' (или нажмите зеленую стрелку рядом с методом).

### Запуск через терминал
Если вы хотите запустить игру без IDE, находясь в корневой папке проекта, выполните:

```bash
# Компиляция
javac src/*.java

# Запуск (убедитесь, что файл Words.txt находится в той же папке, откуда вы запускаете, или укажите правильный путь в коде)
java -cp src Program
```

## Как играть
1. Запустите программу.
2. Следуйте инструкциям в консольном меню.
3. Вводите буквы, чтобы угадать загаданное слово.
4. Следите за количеством оставшихся попыток.

## Примечание
В консоли при остановке программы вручную может отображаться код завершения 130. Это нормально, так как процесс был прерван пользователем (например, через Ctrl+C или кнопку Stop в IDE).
